# Pulso Workout (web)

The web version of the Pulso gym workout tracker, served with GitHub Pages:
**https://ivo-2025.github.io/pulso-web/**

This repository only holds the compiled app (JavaScript, WebAssembly, images
and fonts). Open the link in Safari on an iPhone and choose
Share → Add to Home Screen to use it like an app. Your data stays in your
browser on your own device.
